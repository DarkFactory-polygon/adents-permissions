# Ручная проверка: приёмка по выводу команд на примерах пользователя (BEH-32)

## MAN-NFR-11-output-only-acceptance

Покрывает: NFR-11. Сценарий: BEH-32. Поставка: DEL-37.
Контрольная дата: `2026-11-23` (`date +%F` → `2026-11-23`).

Приёмка закрывается одной сверкой: напечатанный вывод команд сравнивается с ожидаемым
выводом из примеров «вход и правильный выход». Никаких иных артефактов (отчётов,
журналов, дампов) для приёмки не требуется и не создаётся.

### 1. Вход

Каталог с единственным файлом `permissions.yaml` — реестр R1 из
`test_clean_environment.md` (8 записей). Перед прогоном снят список файлов
(`ls -A` → `permissions.yaml`).

### 2. Сверка вывода `check` с ожидаемым

Команда: `python -m agentperm check АГЕНТ ДЕЙСТВИЕ РЕСУРС`.

| Вход | Ожидаемый вывод | Напечатанный вывод | Код | Совпало |
|---|---|---|---|---|
| `check build-bot read repo/app` | `разрешено: выдал alice, до 2026-12-31 (запись 1)` | `разрешено: выдал alice, до 2026-12-31 (запись 1)` | 0 | да |
| `check build-bot write repo/app` | `разрешено: выдал alice, до 2026-11-23 (запись 2)` | `разрешено: выдал alice, до 2026-11-23 (запись 2)` | 0 | да |

| `check deploy-bot deploy cluster/stage` | `разрешено: выдал dave, до 2026-11-25 (запись 7)` | `разрешено: выдал dave, до 2026-11-25 (запись 7)` | 0 | да |

### 3. Сверка вывода `expired` с ожидаемым

Команда: `python -m agentperm expired` (код 0).

Ожидаемый вывод — группы «Просроченные» (записи 8, 3) и «Истекающие в ближайшие
7 дней» (записи 2, 7, 5):

```text
Просроченные:
  agent=deploy-bot resource=cluster/stage action=deploy granted_by=erin until=2026-11-20
  agent=deploy-bot resource=cluster/prod action=deploy granted_by=bob until=2026-11-22
Истекающие в ближайшие 7 дней:
  agent=build-bot resource=repo/app action=write granted_by=alice until=2026-11-23
  agent=deploy-bot resource=cluster/stage action=deploy granted_by=dave until=2026-11-25
  agent=audit-bot resource=repo/app action=read granted_by=bob until=2026-11-30
```

Напечатанный вывод совпал с ожидаемым построчно; записи 1, 4, 6 в выводе отсутствуют.

### 4. Артефакты помимо вывода команд

- `ls -A` после всех прогонов: по-прежнему только `permissions.yaml`; файлов, новее
  снимка до прогона, в каталоге нет.
- Инструмент за время приёмки не создал ни отчётов, ни журналов аудита (ни в каталоге
  приёмки, ни рядом с установленным пакетом); всё, что он выдал, — текст в stdout/stderr
  и код выхода. Закрытие приёмки опирается только на сверку из пунктов 2 и 3.

### Итог

Напечатанный вывод обеих команд совпал с ожидаемым на всех примерах, посторонних
артефактов нет → **зелёный** на BEH-32 (прогон 2026-11-23).
